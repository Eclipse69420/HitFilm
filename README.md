## ✨ Editing and Compositing

HitFilm supports editing and compositing in the same workspace. Editing is about arranging and trimming footage. Compositing is about combining layers, effects, and visual elements so they look like part of the same scene. For an average user, this means you can improve a clip without exporting it to another program.

Use effects with restraint. A short fade, a color adjustment, or a simple motion effect can make a scene feel more polished. Too many effects at once can distract from the content. Add one change, preview it, and decide whether it improves the video. If it does not, remove it and try something simpler.

Layers let you place one element over another. For example, you can put a title over a video clip or place an image in a corner while the main video continues. Keep layers organized by naming them clearly. When a project grows, clear names make it easier to find the element you want to adjust.

## 🎚️ Audio and Timing

Good video also depends on clear audio. Check the sound level of each clip and make sure important speech is not buried under music. If a clip is too quiet, raise its volume. If music is too loud, lower it. Use short transitions between scenes when a hard cut feels abrupt. Timing matters: a scene that stays too long can feel slow, while a scene that changes too quickly can feel confusing.

Preview the whole project from start to finish before exporting. Watch for moments where the audio jumps, where a title disappears too soon, or where a clip ends before the action is finished. These small issues are easy to fix during editing.
